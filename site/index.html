Responder é fácil.

O FoodFlow AI explora justamente esse caminho: fatos antes do texto, confirmação antes da ação e rastreabilidade depois dela.

07 PERGUNTAS FREQUENTES/ TRANSPARÊNCIA

As respostas
sem rodeios.

O FoodFlow AI é um produto do iFood? +

Não. É um projeto independente de portfólio, sem vínculo com o iFood ou com operações reais de delivery.

A demonstração deste site usa IA de verdade? +

Não. Esta página é uma simulação visual e determinística de três fluxos documentados. O projeto original possui um adaptador para LLM, mas sua execução online ainda não foi realizada.

O que acontece quando confirmo um ticket aqui? +

Somente a interface muda para ilustrar a decisão. Este site não envia dados ao backend nem persiste solicitações. A persistência real em SQLite pode ser observada no aplicativo local.

Posso instalar e testar o protótipo? +

Sim. A release pública v1.0.0 disponibiliza um pacote Windows. O código-fonte também pode ser executado localmente com Python 3.12. Leia as instruções e os limites antes de utilizar.

Como o projeto foi desenvolvido? +

Com direção, requisitos e validação humana, além de implementação assistida pelo Codex. O repositório apresenta arquitetura, código, evidências de testes e limitações do projeto.
